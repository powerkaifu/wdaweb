# 泰山職訓「前端網頁技術與AI應用」招生推廣與成果展示網

本網站為勞動部勞動力發展署北基宜花金馬分署 泰山職業訓練場 自辦職前訓練「**前端網頁技術與AI應用**」專班之師資自主推廣宣傳與學員成果展示平台。

---

## 🎯 網站主要功用

本網站旨在為有意轉職前端工程師、對網頁技術與 AI 協同開發感興趣的待業民眾與青年，提供完整、透明且具備現代科技感之課程資訊與成果展示：

1. **920 小時扎實培訓路徑介紹**
   - 清楚呈現課程四大實踐階段：基礎排版（HTML/CSS/Tailwind）、前端工程化（Vue 3/TypeScript/Pinia）、前後端串接與整合，以及現代 AI 工具（GitHub Copilot/Cursor）協同開發實務。
   - 展示一人獨立雙螢幕高階實作設備與沉浸式教室環境。

2. **學員專題成果作品集展示**
   - 收錄歷屆學員結訓前獨立構思與開發之完整 Web 作品集（包含即時線上 Demo 與 GitHub 原始碼）。
   - 展現零基礎跨領域轉職者經過 920 小時密集實戰後的真實技術底氣與就業競爭力。

3. **招生期別時程與進度透明化**
   - 提供各期別之報名起訖日、甄試日期、受訓期間與名額規劃。
   - 以視覺化五階段步進流程呈現班級生命週期，方便民眾即時掌握最新開班動態。

4. **官方報名管道指引與不收集個資原則**
   - **本網站不收集、不留存任何訪客或民眾之個人資料**（全站無留單表單，保障民眾隱私與資訊安全）。
   - 全面引導有意參訓之民眾，直接前往勞動部官方「**台灣就業通**」平台完成身分審查與正式報名手續。

5. **參訓常見問題 (FAQ) 與社群諮詢**
   - 彙整民眾最關心的非本科零基礎參訓資格、政府 100% 全額免費受訓補助、每月職業訓練生活津貼請領條件、學員宿舍申請規範及結訓就業輔導等解答。
   - 提供專班 Discord 線上社群交流管道與職訓場官方諮詢電話。
