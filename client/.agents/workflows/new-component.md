# 工作流：從零建立新 Vue 3 組件

觸發條件：使用者說「新增組件」、「建立 Section」或「我要一個 X 區塊」。

## 觸發技能

啟動 add-section 技能並依序完成所有步驟。

## 完成定義（Definition of Done）

- [ ] 新 Section 組件已建立於 components/sections/ 目錄
- [ ] TypeScript 型別已在 types/index.ts 定義
- [ ] API 請求方法已在 api/client.ts 新增
- [ ] Pinia Store 已整合新 Action
- [ ] App.vue 已正確引入新組件
- [ ] npm run build 執行成功，零 TypeScript 錯誤
- [ ] 組件在瀏覽器中正確渲染資料
