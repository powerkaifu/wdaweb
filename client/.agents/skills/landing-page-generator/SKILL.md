# 技能：招生推廣 Landing Page 高轉換率架構師

## 1. 核心定位與設計哲學
本技能專門針對「官方職訓／專業課程招生宣傳展示網站」而設計。
核心使命是：**在不收集個資的前提下，將目標訪客（求職者、待業者、轉職青年）以最高流暢度引導至官方報名渠道（台灣就業通）。**

## 3. 落地頁關鍵轉換率（CRO）法則

### 法則一：3 秒掃視留客原則（3-Second Glance Test）
- 首屏 Hero 必須讓訪客在 3 秒內一眼看懂：
  1. **我是誰**：勞動部自辦職前訓練（官方政府背書）。
  2. **學什麼**：前端網頁技術與 AI 應用（現代高薪技能）。
  3. **受惠資格**：待業者享 100% 全額免費培訓 ＋ 受訓生活津貼。
  4. **現在該做什麼**：醒目發光的主 CTA 按鈕直通「招生期別與報名」。

### 法則二：大器單行標題與閱讀呼吸律動
- **桌機單行標題**：全站區塊大標題（14~20 字）在桌機（1024px+）一律維持單行大器展示，嚴禁隨意 `<br />` 切割成短碎行。
- **老花眼友善底線**：所有說明內文、卡片敘述維持 `text-base`（16px）以上，行高 `1.7~1.8`，字字舒展，杜絕長輩瞇眼吃力感。
- **4 欄網格防碎防窄**：卡片式網格必須推遲至 `xl:grid-cols-4`（1280px+）啟用，筆電螢幕（1024px~1279px）維持 2 欄寬版，確保文字行長在 40~50 字黃金區間內。

### 法則三：社會認同（Social Proof）心智模型
- 展示真實專題時，提供「線上 Demo」與「GitHub 源碼」雙軌檢驗，卡片採用 3D 浮起與發光微互動，消除民眾對受訓成效的疑慮。

### 法則四：雙期別時間軸心理引導
- 當兩期同時展示時（如第 1 期培訓中、第 2 期待開訓）：
  - 進行中班別標註「已開訓 · 受訓中」（灰階降權，展現穩定訓練軌跡）。
  - 即將開班標註高光標籤與倒數計時（視覺焦點中心）。
  - 當所有班別均未在開放報名窗口時，下方 CTA 按鈕自動轉為「加入 Discord 搶先接收下期開班快訊」，無縫接住流量。

## 4. 全專案強制約束檢查清單
在實施任何 Landing Page 組件變更前，務必確認：
- [ ] 是否完全使用 Django CMS（`useCmsStore`）作為動態資料源，絕不在 UI 硬編碼期別、電話或連結？
- [ ] 是否在無網路或後端冷啟動時具備 0.01 秒本地快取與 Fallback 預設值？
- [ ] 按鈕點擊熱區是否達到 `>= 44x44px`？
- [ ] 所有外鏈（台灣就業通、Discord）是否皆具備 `target="_blank" rel="noopener noreferrer"` 與無障礙 `aria-label`？
